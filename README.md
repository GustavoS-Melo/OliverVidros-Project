# Oliver Vidros — Website Institucional

Projeto desenvolvido para a empresa Oliver Vidros, com o objetivo de criar um site institucional moderno, responsivo e funcional, fortalecendo a presença digital da marca e facilitando o contato com clientes.

Este é um projeto real, desenvolvido sob demanda do cliente e atualmente em produção.

## Sobre o projeto
O site apresenta informações institucionais da empresa, serviços oferecidos, canais de contato e uma navegação simples e objetiva, priorizando clareza, performance e boa experiência do usuário em diferentes dispositivos.

Todo o desenvolvimento foi feito considerando as necessidades do cliente, desde o layout até a publicação em servidor próprio.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Deploy
O site está hospedado em servidor próprio do cliente.

Acesso em produção:  
https://olivervidros.com.br

## Responsabilidades no projeto
- Desenvolvimento completo do front-end
- Estruturação das páginas e estilos
- Implementação de interações com JavaScript
- Publicação e configuração do site em servidor próprio do cliente

## Observações
Por se tratar de um projeto comercial real, o repositório contém apenas o código referente ao site, sem informações sensíveis ou dados internos da empresa.
